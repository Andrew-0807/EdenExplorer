# Handoff: EdenExplorer to Axis (2026-11-10)

The new product name is **Axis**. This repo is the user's own fork of mtucciarone/EdenExplorer v1.3.0 and will go its own way from the original.

## Where things are

- **Fork:** `https://github.com/Andrew-0807/EdenExplorer`, remote `fork`. Push every branch here.
- **Push auth:** the Windows credential store fails. Push with:
  `git -c credential.helper= -c credential.helper='!gh auth git-credential' push fork <branches>`
- **Integration branch:** `preview/integration`, worktree `G:\projects\EdenExplorer\.claude\worktrees\integration`. Head is `aff138c8`, already pushed.
- **Preview exe:** `G:\projects\EdenExplorer\.claude\audit\preview-bin\EdenExplorer.exe`. The desktop launcher `EdenExplorer-preview.cmd` starts it with the data folder `G:\projects\EdenExplorer\.claude\audit\eden-preview-data`.
- **Build:**
  - Use `CARGO_TARGET_DIR=G:/projects/EdenExplorer/.claude/worktrees/zoxide/target`.
  - Agents build into `D:/cargo-targets/<name>` because G: is about 97% full.
- **Render tool (stageshow):**
  - Command: `STAGESHOW=1 cargo test stageshow -- --nocapture`.
  - Scenes live in `src/gui/stageshow.rs` and use egui_kittest and wgpu. They render offscreen, so they work in session 0.
  - PNGs land in `docs/stageshow/` and are gitignored.
  - Use it for all UI work.
- **Commit rules:**
  - Run `git checkout -- Cargo.lock` before every commit. The only exception is a commit that adds a dependency.
  - No co-author lines.
  - Never use bare `git stash`.
- **Baselines:** 238 tests pass. Clippy shows 176 warnings, which predate this work.

## Known caveats

- A late size result can briefly show a stale value.
- The hotkey editor isn't covered by settings search.
- Modifier matching is exact: Ctrl+Shift+T no longer opens a new tab.
- "Reset all" shortcuts has no confirmation.
- Undo can't restore tags after a delete.
- OneDrive placeholder folders show 0 or a partial size.
- Menus are egui popups, not acrylic.
